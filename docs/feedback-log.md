## Ideas already on the list

Things that came up while building version 1.x and haven't been done yet:

- **Lock-screen alerts** for events and nudges. This needs push notifications, which iPhones allow for home-screen web apps but which require a small sending service.
- **Quick add from anywhere:** an iPhone Shortcut that adds an item without opening the app, or turns an email-to-self into an item.
- **Calendar link:** show Google Calendar appointments on the Days tab, or export RTD events to the calendar.
- **Daily Dose:** a place to log or link athlete check-ins from the training app.
- **Shared lists** for a team or family.
- **Moving one date of a repeating event** to another day (today you can add a note or skip it).
- **Free AI help built in:** a review, next moves and follow-up drafts using a free AI service. Today, "Copy my week as text" covers this.
- **Monthly and yearly views** of the journal and patterns.
- **Dark mode switch** (today it follows the phone's setting).
